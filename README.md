# Thiranex Data Science Internship - Task 3

### Objective
Performed Exploratory Data Analysis (EDA) on the Ames Housing dataset to identify key features affecting house prices.

### Key Steps
1. **Correlation Analysis:** Generated a heatmap to identify the top 10 features most strongly correlated with `SalePrice`.
2. **Feature Analysis:** Used box plots to visualize the relationship between `OverallQual` and `SalePrice`, revealing a clear positive correlation.

### Results
- `OverallQual` and `GrLivArea` are the most significant predictors of house prices.
- Higher quality ratings consistently lead to higher sale prices.

### Tools Used
- Python, Pandas, Matplotlib, Seaborn.
